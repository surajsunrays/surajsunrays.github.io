# Suraj Bodade — Portfolio

A responsive, dependency-free portfolio built with HTML, CSS, and JavaScript.

Open `index.html` in a browser, or serve the directory locally:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

Edit `index.html` to update portfolio content, `styles.css` for presentation, and `assets/resume/Suraj_Lead_DevOps_June2026.pdf` for the downloadable resume. Google Fonts are optional; system sans-serif fonts provide a fallback. Deploy these files to any static web host.

Credentials reflect the resume; current certification validity and verification URLs are not supplied, and visible over linkedin profile.

Google Skills achievements were imported from the linked public profile on September 5, 2026. Source titles, earned dates, artwork URLs, and verification links are recorded in `assets/badges/google-skills.json`. These learning achievements are separate from professional certifications; the profile points are a dated snapshot.

The portfolio features eight relevant Google Skills badges from the ten imported records. Agent Fundamentals and the ACE exam study-guide badge are omitted from the displayed selection.
